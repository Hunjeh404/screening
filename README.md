미국 실적 신고가 스크리너

뉴욕증권거래소·나스닥 상장사 가운데 매출 또는 영업이익이 분기 기준과 최근 4분기 합계 기준으로 모두 사상 최고인 종목을 찾고, 버핏식 품질·안전마진 조건과 차트 보조 조건으로 거르는 웹앱입니다.

구성
docs/index.html  웹앱 (GitHub Pages로 공개)
docs/data.json   스크리닝 결과 (처음에는 가상의 샘플 데이터)
scripts/fetch.py SEC 재무(companyfacts 일괄 파일)와 야후 시세를 받아 data/cache에 저장
scripts/screen.py 지표를 계산해 docs/data.json 생성
.github/workflows/daily.yml 화~토 07:47(한국시간)에 위 두 스크립트를 자동 실행

처음 설정
1. Settings > Pages에서 Source를 Deploy from a branch, 브랜치 main, 폴더 /docs로 지정합니다.
2. Actions 탭 > daily-screen > Run workflow로 첫 실행을 합니다. 첫 실행은 업종코드를 회사마다 조회하느라 시간이 더 걸리고, 이후에는 저장해 둔 값을 씁니다.
SEC는 실제 연락처가 담긴 신원 정보를 요구합니다. Settings > Secrets and variables > Actions에서 SEC_USER_AGENT라는 시크릿을 만들고, 값에 영문 이름과 본인 이메일을 띄어 써서 넣습니다(예: Hong Gildong you@gmail.com). GitHub 익명 이메일(noreply)은 거부됩니다.

기본 필터 (화면에서 조절)
일반 기업: 3년 평균 ROE 15% 이상, 부채비율 50% 이하, 10년 연속 영업흑자, PER이 5년 중앙값보다 낮음
금융업(SIC 60~64, 67): PBR 1배 이하, 3년 평균 ROE 10% 이상
차트 보조: 종가가 120일선 또는 240일선 위, 최근 20일 변동성이 60일 변동성보다 작음

계산 기준과 한계
SEC XBRL 재무는 대체로 2009~2011년부터 있어서 사상 최고는 그 이후 기준입니다.
4분기 실적은 따로 공시되지 않아 연간 실적에서 1~3분기(또는 9개월 누적)를 빼서 구합니다.
분기 라벨은 회계분기가 아니라 달력 분기(결산일 기준)입니다.
매출은 회사마다 쓰는 항목 이름이 달라 여러 항목 중 가장 큰 값을 씁니다. 영업이익을 공시하지 않는 회사(은행 등)는 세전이익으로 대신합니다.
과거 PER은 분기 말 종가에 현재 발행주식수를 곱해 계산하므로 증자·자사주 매입이 컸던 종목은 오차가 생깁니다.
해외 기업이 미국에 상장한 종목(20-F 제출)과 스팩은 대상에서 빠집니다.
그레이엄 내재가치 = √(22.5 × EPS × BPS), EPS는 최근 4분기 순이익 기준입니다.
