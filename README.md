# 종목 검색기 (미국·한국)

SEC/DART 재무와 일별 종가로 매수 후보를 찾고, 최초 편입 이후 매수·보유·매도 상태를 추적합니다. GitHub Pages의 `/docs`에서 제공합니다. 실제 주문을 전송하는 기능은 없습니다.

## 구조

- `scripts/fetch.py`, `fetch_kr.py`: 재무·일별 시세 수집 및 20·120·200일선, 일간 등락률, 20·60일 변동성 계산
- `scripts/lib.py`, `lib_kr.py`: 분기/TTM 재무 및 가치 지표 계산
- `scripts/card_rules.py`: 매수·보유·매도 판정, 목표가/손절가, OBV 및 이력 저장의 단일 기준
- `scripts/screen.py`, `screen_kr.py`: 두 시장의 데이터와 이력 생성
- `docs/data.json`, `docs/data_kr.json`: 시장별 결과 (schema version 2). 화면에 나오는 매수·보유·매도 종목만 담고, 전체 분석 종목 수는 `meta.count`입니다.
- `docs/card_history.json`: `us:티커` / `kr:티커`별 최초 편입일·편입가·직전/현재 상태·최고 종가·전이 기록·마지막 유효 스냅샷. 첫 정상 실행부터 생성합니다.
- `docs/index.html`, `app.js`, `styles.css`: 정적 화면. 검색조건·섹터·카드는 기본 접힘입니다.
- `.github/workflows/daily.yml`: 화~토 07:47 KST, 수동 실행 또는 계산 코드 변경 시 갱신. 시장별 결과와 이력을 즉시 커밋합니다.

## 편입 및 상태

매수 편입에는 단일 분기와 TTM의 매출 또는 영업이익 동시 신고가, 종가 ≥ 120일선 또는 200일선, 20일 변동성 < 60일 변동성, OBV 이탈 없음이 필요합니다.

- 일반 기업: ROE 3년 평균 ≥ 15%, 부채비율 ≤ 50%, 연속 영업흑자 ≥ 5년, 양의 PER < 5년 중앙값.
- 금융업: PBR ≤ 1배, ROE 3년 평균 ≥ 10%.
- 비금융 적자 턴어라운드: TTM 영업이익 적자이고 단일 분기·TTM 매출 동시 신고가이며, 분기 영업이익이 2분기 연속 개선(전전분기 < 전분기 < 최근 분기)되고 F-스코어가 미국 9개 항목 중 7점, 한국 6개 항목 중 5점 이상이어야 합니다. 순이익만 적자인 회사(일회성 손실 등)는 일반 기업 조건으로 판정합니다. 이 경로에는 일반 기업의 흑자·ROE·부채·PER 요건을 적용하지 않습니다.
- F-스코어(피오트로스키)는 최근 4분기 합계와 1년 전을 비교합니다: ROA 양수, 영업현금흐름 양수, ROA 개선, 영업현금흐름 > 순이익, 장기부채 비중 감소, 유동비율 개선, 신주 발행 없음, 매출총이익률 개선, 자산회전율 개선. 한국은 DART 일괄 조회에 현금흐름·매출총이익이 없어 이 3개를 뺀 6개 항목이며, 신주 발행은 자본금 증가로 판단합니다. 계산할 수 없는 항목은 0점입니다.

매도 상태는 5번의 갱신일 동안 표시하고 6번째 갱신에서 이력까지 지웁니다(같은 날 재실행은 1회, 매도에서 벗어나면 다시 셈). 거래소 상장 목록에서 빠진 종목(상장폐지)은 상태와 관계없이 이력까지 지웁니다. 지운 종목이 다시 조건을 충족하면 새로 편입합니다.

매도 조건을 매수 조건보다 먼저 판정합니다. 최초 편입 이력이 없는 종목은 고평가에 나타나지 않습니다. 기존 편입 종목은 조건 이탈 시 보유, 추세이탈/수급악화/투매/피크아웃/적자전환/공시지연 중 하나라도 발생하면 매도로 전환됩니다. 매도 조건이 사라지고 매수 조건도 불충족이면 보유로 전환하며, 매수 조건을 다시 충족하면 매수로 전환합니다. 최초 편입과 상태 전이 이력은 보존합니다.

- 추세이탈: 종가가 두 장기 이평선 모두의 98% 미만
- 수급악화: 52주 OBV 이탈
- 투매: 변동성20 > 변동성60, 종가 < MA20, 일간 등락률 ≤ −7%
- 피크아웃: 최신 TTM 매출 및 영업이익이 직전 TTM보다 모두 감소
- 적자전환(일반): 최신 분기 영업손실 또는 ROE < 12% 또는 부채비율 > 70%
- 금융/적자 턴어라운드 예외: 금융 ROE < 8% 또는 영업적자로 편입했던 턴어라운드의 단일 분기 매출 신고가 실패
- 공시지연: 시장 내 최신 재무 분기보다 2분기 이상 지연

보유 사유는 상승중·적정가치·눌림목·지지 테스트·실적유지·재무보합·흑자 연수 미달·영익 개선 미달·F-스코어 미달을 중복 표시합니다. 턴어라운드 경로는 매출 신고가만 보므로 영업이익 신고가 실패를 실적유지로 표시하지 않습니다. 어느 명시 조건에도 해당하지 않으면 ‘매수조건 미충족’으로 표시합니다. 초기 이력은 첫 정상 실행에서 실제 충족 종목만 기록하며 과거 편입을 소급 추정하지 않습니다. 수집 누락 시 마지막 상태·데이터를 보존하고 수집 지연 표시를 붙입니다.

## 수익률과 가격

요청된 `calc_card_metrics` 수식을 적용합니다. 최소 손절폭은 −5%, 일반주 최대 −7%, $0.3B 이하/PER 미산출은 최대 −10%입니다. 적자 턴어라운드는 일반주보다 좁게 최소 −3%, 최대 −5%입니다. 1차는 2R 또는 200일선 저항까지 상승률 중 큰 값, 2차는 PER/PBR 회귀 수익률·3R·1차+7%p 중 최대값입니다. 52주 고점은 목표가 계산에 사용하지 않습니다.

화면 하단에는 예상 손실률과 목표 수익률(1차), 목표 수익률(2차)만 표시합니다. 손절가·목표가·편입 및 상태 전이 이력·TS 안내는 화면에서 제외하고 계산과 이력 저장은 유지합니다. 자동 주문·추적 손절 엔진은 아닙니다. 고평가 발동은 위 여섯 조건만 사용합니다. 한국 시총은 실제 USD/KRW 환율로 달러 환산합니다. 환율/시총이 누락되면 최대 손절폭은 보수적으로 −10%를 적용합니다.

## 화면과 링크

미국/한국 선택과 저평가/적정가치/고평가 탭은 한 줄에 배치됩니다. 탭은 매매 상태의 표시 이름으로 저평가=매수(BUY), 적정가치=보유(HOLD), 고평가=매도(SELL)입니다. PER/PBR이 특정 값과 같거나 큰지로 탭을 나누지 않습니다.

적정가치에는 과거 매수 이력이 있고, 현재 매수 필요조건과 매도 조건을 모두 충족하지 않는 종목이 표시됩니다. 매도 조건을 우선 확인합니다. 섹터는 종목 수 내림차순, 섹터 안 종목은 시총 내림차순입니다.

PER·5년 중앙값 또는 금융업 PBR이 부족한 경우 같은 상태의 탭 안에서 ‘가치평가 기준 미달’ 영역으로 모아 보여줍니다. 동일 문구의 카드 태그는 표시하지 않습니다. 실제 TTM 순이익 또는 영업이익이 음수이면 ‘적자’ 태그를 표시하며, PER 미산출만으로 적자라고 판정하지 않습니다.

종목명/티커 링크는 Android에서 TradingView 패키지 intent와 웹 fallback을 사용합니다. iOS/PC는 티커 단독 웹 URL입니다. 카드 여백·태그를 누르면 모든 상세 데이터가 펼쳐지고 다시 누르면 접힙니다. OS/브라우저가 외부 앱 실행을 제한하거나 앱이 없으면 앱 실행 자체를 보장할 수는 없습니다.

검색조건은 사용자 확인에 따라 입력칸 없이 항목별 태그로 표시합니다. 기본적으로 접혀 있으며 편입 기준과 이력은 배치에서 관리합니다.

## 일봉 신호와 카드 지표

`scripts/hunbot.py`에서 일봉 고가·저가·종가로 HunBot 지표를 계산합니다. 당일 미완성 봉은 제외합니다(미국 정규장 16:00 뉴욕 시간, 한국 15:30 서울 시간 이후 확정; 미국 단축장은 보수적으로 16:00까지 기다림).

- RSI는 Wilder RMA(SMA 초기값), EMA는 첫 유효값을 초기값으로 사용합니다. 볼린저밴드는 20일 모집단 표준편차의 2배입니다.
- `lc`: 종가 ≥ SMA5, bungee 아님, RSI12와 EMA 평활 스토캐스틱 K가 각각 10 초과·85 미만, K/D 상향 교차.
- `sc`: 초강세가 아니고, 종가가 볼린저 중심선 위이면 상단밴드 하향 교차, 그 외에는 K/D 하향 교차.
- 삼각형은 발생 봉 D+0부터 D+2까지 유지합니다. D+3 또는 sc 발생 시 삭제하며, 동일 봉에서는 sc가 우선입니다. 주말/휴일이나 배치 재실행으로 경과 일수를 늘리지 않습니다.
- 초강세: 종가 > SMA5, 볼린저 중심선 상승, 스토캐스틱(20,12,12) 두 번째 EMA 비하락.
- 추세의 패닉셀: EMA(RSI20,12) ≤ 30. 기존 매도 사유인 ‘투매’와 별개이며, 초강세와 겹치면 둘 다 태그로 표시합니다.
- LC/SC와 초강세·패닉셀 태그는 표시용으로, 매매 상태 분류 조건을 추가하지 않습니다. 고가·저가 또는 지표 준비 기간이 부족하면 신호를 만들지 않습니다.

섹터를 열면 접힌 카드에도 현재가(당일 등락률)·120일선 가격·200일선 가격이 표시됩니다. 이평선 이격률 숫자는 숨기고 현재가가 해당 선보다 위이면 선의 가격을 청록색, 아래이면 분홍색으로 표시합니다. 상세 그리드는 3열×2행으로 ROE 3년, PBR/부채비율, PER(5년 중앙), 52주 고점 대비, 시가총액, 기준정보(재무분기) 순서입니다. 거래소·분기 태그는 표시하지 않습니다.

상승추세의 표시 이름은 상승우위입니다(분류 조건 동일). 매출·영익은 기존 신고가 태그의 축약명입니다. 카드 태그를 누르면 조건과 실제 수치를 팝업으로 확인하며 카드 접힘 상태는 유지됩니다. 상세 지표값이 아직 수집되지 않은 경우 수치는 ‘–’로 표시합니다.

티커 오른쪽 공유 아이콘은 현재 카드의 전체 상세정보와 테두리를 JPG로 저장합니다. 접힌 카드도 펼친 복제본을 렌더링하며 화면의 접힘 상태를 바꾸지 않습니다. 종목명은 저장 이미지에서 생략하지 않습니다. 렌더러 html2canvas 1.4.1은 MIT 라이선스로 docs/vendor에 포함합니다.

## 실행 및 검증

Settings → Pages: main의 `/docs`. Actions 시크릿에 `SEC_USER_AGENT`(실제 연락처 포함), `DART_API_KEY`를 등록합니다. 한국 수집 실패 시 이미 게시된 미국 결과를 유지합니다. 수집 중간 캐시도 저장하여 다음 실행에서 이어갑니다.

```sh
python -m unittest discover -s tests -v
node tests/test_ui.cjs
python scripts/fetch.py
python scripts/screen.py
python scripts/sectors.py
python scripts/fetch_kr.py
python scripts/screen_kr.py
python scripts/sectors.py data/cache/kr docs/data_kr.json
```

## 데이터 한계

SEC XBRL 과거 재무는 대체로 2009~2011년부터, DART는 2015년부터여서 신고가는 확보된 기간 기준입니다. 4분기는 연간에서 누적 3분기를 차감합니다. 분기 라벨은 달력 분기이며 영업이익 미공시 금융사는 세전이익을 사용합니다. 과거 PER은 현재 발행주식수를 사용하므로 증자/자사주 매입 영향이 있습니다. OBV는 52개 주간 변화가 있어야 판정하며 부족하면 미산출입니다. 최신 시세는 수집된 일별 종가이며 현재가라는 표기는 실시간 호가를 의미하지 않습니다.

종목명 뒤 노란색 가운데점(·)은 해당 시장의 최신 데이터 갱신일에 현재 분류로 신규 편입된 종목을 표시합니다. 최초 편입과 분류 이동을 포함하며, 같은 날 재수집 시 유지되고 다음 갱신일에는 해제됩니다. 수집 실패로 유지된 종목에는 붙이지 않습니다.
